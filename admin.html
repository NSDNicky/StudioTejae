Production integration checklist

1. Add business email and WhatsApp number in config.js.

2. Create a secure HTTPS endpoint in your own backend or trusted automation service. Configure the endpoint to receive JSON POST lead requests, validate data, and forward them to your CRM.

3. Enter its public URL as webhookUrl in config.js. Configure CORS, rate limits, anti-spam measures and privacy/consent handling on your backend.

4. Set up a protected CRM admin page separately. Never expose private CRM tokens in public client-side code.

5. Add calendar availability checking and booking confirmation if you want confirmed slots rather than requests.
